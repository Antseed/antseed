# @antseed/website

Marketing and documentation website for Antseed.

## Development

```bash
pnpm run dev        # Start the Docusaurus dev server
pnpm run build      # Production build into build/
pnpm run preview    # Serve the production build
pnpm run typecheck  # Type-check with tsc
```

## Tech Stack

- Docusaurus 3 (classic preset: docs, blog, pages)
- React 19
- CSS modules and global CSS (`src/css/`)
- TypeScript

## Content

| Path | Route | Description |
|------|-------|-------------|
| `src/pages/` | `/`, `/providers`, `/network`, ... | Marketing pages |
| `docs/` | `/docs/...` | Documentation, ordered by `sidebars.ts` |
| `docs/lightpaper.md` | `/docs/lightpaper` | Lightpaper |
| `blog/` | `/blog/...` | Blog posts |
| `src/integrations/` | `/integrations/<slug>` | Integration pages, generated by `plugins/integrations-pages.ts` |

`plugins/docs-search.ts` builds the docs search index, with no external search service.
